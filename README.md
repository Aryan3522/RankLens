# RankLens

SEO Intelligence Platform.

## 🚀 How to Run Locally

### 1. Backend (Server)
1. `cd server`
2. `npm install`
3. `npm run dev`

### 2. Frontend (Client)
1. `cd client`
2. `npm install`
3. `npm run dev`

---

## 📁 Structure
- `client/`: Independent React + Vite frontend.
- `server/`: Independent Express + Node.js backend.
