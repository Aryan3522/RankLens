# RankLens

**Real-time SEO Intelligence Platform** — Analyze websites, YouTube videos, and Instagram posts with live HTML crawling, detailed issue cards, fix examples, and AI-powered recommendations.

## Stack
- Frontend: React + Vite + Tailwind + shadcn/ui
- Backend: Express 5 + TypeScript
- Database: PostgreSQL + Drizzle ORM
- Crawler: Cheerio (real HTML parsing)

## Features
- Real website SEO crawling (meta tags, headings, images, links, OG tags, schema)
- YouTube analysis via oEmbed API
- Instagram post analysis via OG tags
- Expandable issue cards with element code snippets, line numbers & fix examples
- Keyword rank tracking with history
- Analytics dashboard
